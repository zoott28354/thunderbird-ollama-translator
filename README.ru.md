Дополнение для Thunderbird, которое переводит электронные письма с помощью локального Ollama - **Полная конфиденциальность**, никакие данные никогда не отправляются в интернет.

## ✨ Возможности

- 🏠 **100% Локально** - Никакие данные не отправляются в интернет, НИКОГДА
- 🌍 **10 языков** - Итальянский, Английский, Испанский, Французский, Немецкий, Португальский, Русский, Японский, Китайский, Корейский
- 🖱️ **Контекстное меню** - Правый клик для перевода на любой язык
- ⚡ **Быстро** - Использует модель translategemma (3ГБ, оптимизирована для переводов)
- 🔒 **Абсолютная конфиденциальность** - Всё обрабатывается локально, без отслеживания
- 🌐 **Многоязычный интерфейс** - Дополнение доступно на 7 языках: 🇮🇹 Итальянский, 🇬🇧 Английский, 🇩🇪 Немецкий, 🇫🇷 Французский, 🇪🇸 Испанский, 🇵🇹 Португальский, 🇷🇺 Русский (автоматически адаптируется к языку Thunderbird)

## 📋 Требования

1. **Ollama** установлен на вашем ПК
   - Скачать с: https://ollama.ai

2. **Модель Ollama** загружена
   - Рекомендуется: `ollama pull translategemma` (3ГБ, оптимизирована)
   - Альтернативы: `llama3.2`, `mistral`

3. **Thunderbird** версии 128 или выше

⚠️ **Важное примечание**: Перед использованием дополнения необходимо настроить `OLLAMA_ORIGINS` (см. раздел "Начальная настройка" ниже).

## 📦 Установка

### Метод 1: Файл XPI (Рекомендуется)

1. **Скачайте** файл `thunderbird-ollama-translator.xpi`
2. **Откройте Thunderbird**
3. Перейдите в **Меню > Инструменты > Дополнения**
4. Нажмите на значок шестерёнки ⚙️ в правом верхнем углу
5. Выберите **"Установить дополнение из файла..."**
6. Выберите файл `.xpi`
7. Подтвердите установку

### Метод 2: Из папки (Разработка)

1. Извлеките файлы в папку
2. Откройте Thunderbird
3. Нажмите **Ctrl+Shift+A** (или из Меню > Инструменты > Дополнения)
4. Нажмите на значок шестерёнки ⚙️
5. Выберите **"Отладка дополнений"**
6. Нажмите **"Загрузить временное дополнение..."**
7. Выберите файл `manifest.json` из папки

## ⚙️ Начальная настройка

### 1. Откройте настройки дополнения
   - Меню > Инструменты > Дополнения > "Ollama Translator" > Настройки

### 2. ОБЯЗАТЕЛЬНАЯ настройка: OLLAMA_ORIGINS

**Почему это необходимо?**
По соображениям безопасности Ollama блокирует запросы от расширений браузера. Вы должны явно авторизовать Thunderbird.

**Рекомендуемое значение (более безопасно):**
```
OLLAMA_ORIGINS=moz-extension://*
```
Разрешает только расширениям Firefox/Thunderbird доступ к Ollama. Блокирует все внешние сайты.

**Как настроить:**

**Windows (CMD):**
```cmd
setx OLLAMA_ORIGINS "moz-extension://*"
```
Затем закройте и снова откройте терминал и запустите Ollama:
```cmd
ollama serve
```

**Linux/Mac (постоянно):**
```bash
echo 'export OLLAMA_ORIGINS="moz-extension://*"' >> ~/.bashrc
source ~/.bashrc
ollama serve
```

**Альтернативный вариант** (если вам также нужны локальные приложения):
```
OLLAMA_ORIGINS=moz-extension://*,http://localhost:11434
```

### 3. Настройте дополнение
   - **Целевой язык**: Итальянский, Английский, Испанский, Французский, Немецкий, Португальский, Русский, Японский, Китайский, Корейский
   - **URL Ollama**: `http://localhost:11434` (по умолчанию)
   - **Проверить соединение**: Нажмите, чтобы проверить доступность Ollama
   - **Модель**: Выберите `translategemma` (рекомендуется) или другую установленную модель

### 4. Сохранить
   - Нажмите "Сохранить"

## 🎯 Как использовать

### Контекстное меню (Рекомендуется)
1. **Откройте письмо**, которое хотите перевести
2. **Правый клик** на теле письма
3. **Выберите "Перевести с помощью Ollama ▶"** и выберите язык
   - Выбранный язык будет отображаться **жирным шрифтом**
   - Этот выбор становится по умолчанию
4. Дождитесь сообщения "Перевод завершён"

### Показать оригинал
- После перевода **правый клик** на тексте
- Выберите **"Показать оригинал"**, чтобы восстановить исходный текст

## 🔒 Безопасность

### ✅ Что безопасно

- **Никакие данные никогда не отправляются в интернет** - Всё обрабатывается локально с помощью Ollama
- **Локальное соединение** - Связывается только с `localhost:11434`
- **Без отслеживания** - Никакой статистики, отслеживания или удалённых логов
- **Без API-ключа** - Не требуется API-ключ или регистрация
- **Открытый исходный код** - Полностью проверяемый код

### 🔐 Требуемые разрешения

Дополнению требуются только эти разрешения Thunderbird:
- `messagesRead` - Читает содержимое письма
- `messagesModify` - Заменяет текст переводом
- `menus` - Добавляет контекстное меню
- `storage` - Сохраняет настройки
- `tabs` - Внедряет скрипт в письмо
- `http://localhost/*` - Для связи с локальным Ollama

**Нет доступа к внешним сервисам**

Нет доступа к:
- ❌ Адресная книга, календарь, чат
- ❌ Учётные данные аккаунта
- ❌ База данных Thunderbird
- ❌ Файловая система (кроме localhost для Ollama)

## 🚨 Устранение неполадок

### "Ошибка: Ошибка Ollama: 403 Forbidden" ⚠️

**ПРИЧИНА**: Ollama блокирует запросы от расширений браузера по соображениям безопасности.

**ПОЛНОЕ РЕШЕНИЕ**:

1. **Остановите Ollama**, если он запущен (Ctrl+C в терминале, где выполняется `ollama serve`)

2. **Настройте переменную окружения** (рекомендуемое значение для безопасности):

   **Windows (CMD):**
   ```cmd
   setx OLLAMA_ORIGINS "moz-extension://*"
   ```

   **Linux/Mac:**
   ```bash
   echo 'export OLLAMA_ORIGINS="moz-extension://*"' >> ~/.bashrc
   source ~/.bashrc
   ```

3. **Закройте и снова откройте терминал**, затем запустите Ollama:
   ```bash
   ollama serve
   ```

4. **Проверьте конфигурацию**:
   - Откройте Thunderbird
   - Перейдите в настройки дополнения
   - Нажмите "Проверить соединение"
   - Должно показать "Соединение успешно: доступно X моделей"

**Примечание**: `moz-extension://*` разрешает только расширениям Firefox/Thunderbird доступ к Ollama, блокируя внешние сайты (более безопасно).
